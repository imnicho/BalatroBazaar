# Balatro Bazaar

A mystical marketplace of decks, jokers, and consumables for [Balatro](https://store.steampowered.com/app/2379780/Balatro/).

## Requirements

- [Steamodded](https://github.com/Steamodded/smods)
- [LOVELY Injector](https://github.com/ethangreen-dev/lovely-injector)

## Installation

1. Install Steamodded and LOVELY per their instructions
2. Copy the `BalatroBazaar/` folder into your Balatro `Mods/` directory
3. Launch Balatro

## Content

### Decks

**Mystic Capitalist Deck** - Duplicate any joker or consumable for a price based on rarity ($10/$20/$30/$50 for Common/Uncommon/Rare/Legendary). Each duplication destroys one other random joker or consumable.
